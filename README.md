# Thermostat
Thermostat pour réguler un chauffage à une tranche de temperature

## Principe
Avoir un esp8266 qui controle un triac, et qui allume ou étant le passage du courrant 
en fonction d'une plage de température définisable depuis un interface web,
qui permet de paramètré la tranche et voir la température.

Avoir une API de communation en HTTP sur ESP8266 connecté en WIFI

Page web herbergé sur mon  site

## Technologies utilisées
Back-end sur l'ESP
Selvte ou Vue pour le compossant
CSS: https://getuikit.com/docs/form
